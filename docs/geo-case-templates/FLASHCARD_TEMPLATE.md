# Geography Case Study Flashcards

Create a small set for each case study. Start with 6–10 useful cards rather than dozens of cards that repeat the same fact. Keep each answer short, precise, and source-checked.

## Reusable cards

| Front (prompt) | Back (answer) |
|---|---|
| Where is **[case study]**? | [Named location and scale] |
| What is the central issue/process? | [One-sentence explanation] |
| Give two causes or contributing factors. | [Factor 1 + link; factor 2 + link] |
| What were two impacts? | [Impact + who/what was affected] |
| What action was taken, and by whom? | [Action, responsible group, intended purpose] |
| What evidence shows the outcome? | [Verified place/date/figure/example + what it demonstrates] |
| What limitation or unresolved problem remained? | [Verified limitation, or CHECK if not established] |
| How could this case support an **explain** question? | [Point → precise evidence → explanation of the link] |
| How could it support an **evaluate** question? | [Benefit + limitation + supported judgement] |

## Rules for strong cards

- Ask one clear question per card.
- Prefer recall prompts over multiple-choice recognition.
- Keep the answer short enough to say aloud, but detailed enough to be accurate.
- Include units and dates with figures.
- Distinguish causes, impacts, responses, and outcomes.
- Avoid cards whose answer is only a vague word such as “pollution” or “management.”
- Never add a statistic simply to make a card look impressive.
- If a fact is uncertain, label it **CHECK** and do not count it as learned.

## Quick self-test

For each case, score yourself honestly:

- **0:** could not recall it;
- **1:** recalled the general idea but not precise evidence;
- **2:** recalled accurate details but struggled to apply them;
- **3:** recalled accurate evidence and used it to answer a question.

Repeat scores 0–2 sooner. A score of 3 is evidence of performance on this attempt, not proof of permanent mastery.
