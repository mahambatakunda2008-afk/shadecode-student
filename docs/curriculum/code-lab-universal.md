# Code Lab: universal content-grounding contract

Code Lab is a universal practice engine. It is not a ZIMSEC product, an O-Level product, or an exam-only product.

## The real alignment chain

`learner -> academic context -> authoritative scope -> complete verified content -> objectives/outcomes/competencies -> topics/concepts/skills -> activity`

Objectives are only one content type. The authoritative scope can contain topics, subtopics, concepts, knowledge, terminology, practical work, projects, assessment requirements, prerequisites, progression and other constraints.

## Alignment rule

An activity is academically aligned only when its learner context matches a complete, verified authoritative scope and every referenced content item is verified. Objective/outcome/competency mappings must also be verified when present.

A verified objective with missing or unverified surrounding content is not a complete curriculum guarantee.

## Adapters

Code Lab uses adapters rather than hard-coded education systems:

- school board + qualification + syllabus/version
- university institution + programme + course/module
- TVET institution/programme + competency/assessment scope
- professional qualification + course/module
- general/unconfigured practice

A new education system adds a scope adapter/content pack, not another Code Lab engine.

## General mode

Learners without a verified academic scope may still use Code Lab. Activities in this mode are general practice and must never be presented as syllabus, course, qualification or assessment aligned.

## Content safety

When authoritative content is missing, Cortex must not manufacture a curriculum. Shadecode Student should clearly distinguish verified academic content from general enrichment and wait for a verified content pack where an alignment claim is required.

## Content packs

ZIMSEC O-Level Computer Science is one important initial production target, especially for the students currently being onboarded. It is not the architecture boundary. Cambridge, other school boards, university, polytechnic/TVET and professional learning contexts use the same content-grounding system.
