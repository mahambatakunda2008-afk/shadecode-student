# Comp Lab Algorithm Curriculum Matrix

## Purpose

This matrix is the board-neutral exercise layer for Comp Lab. It deliberately does **not** claim to reproduce official ZIMSEC or Cambridge wording. Official curriculum mappings are attached only when a verified syllabus source is available.

## Progression

| Stage | Core algorithm skills | Comp Lab evidence |
|---|---|---|
| School | sequence, input/output, simple selection, simple loops | run result, trace, explanation |
| Secondary | selection, iteration, arrays, validation, testing, trace tables | visible + protected practice cases, trace evidence |
| Sixth form | structured algorithms, arrays, subroutines, testing, complexity, flowcharts | multi-case execution, hidden cases, complexity evidence |
| University | decomposition, data structures, algorithm analysis, testing | project/runtime evidence, complexity, tests |
| Polytechnic | practical problem solving, structured programming, databases, applied algorithms | artifact + runtime + test evidence |
| Professional | maintainability, performance, edge cases, architecture | project graph, tests, diagnostics, performance evidence |

## Objective map

- `alg.input-output` → input, output, assignment
- `alg.sequence` → ordered problem solving
- `alg.selection` → IF/ELSE/CASE
- `alg.iteration` → FOR/WHILE/REPEAT
- `alg.arrays` → arrays, lists, indexed processing
- `alg.subroutines` → procedures, functions, decomposition
- `alg.tracing` → dry runs, trace tables, state changes
- `alg.testing` → normal, boundary, invalid and regression tests
- `alg.complexity` → time/space growth and efficiency
- `alg.flowcharts` → algorithm representation and consistency

## Required curriculum binding

Every official board mapping must preserve:

`board → qualification/level → subject → syllabus → objective → skill → exercise → evidence`

The mapping record must include a syllabus version and a verifiable official source reference. If either is missing, the exercise remains board-neutral.

## Assessment rule

Practice execution can be browser-first. Authoritative assessment must execute protected cases outside the client bundle and return only the minimum result needed for scoring and Learning Graph evidence.
