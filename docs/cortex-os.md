# Cortex OS

Cortex OS is the central intelligence layer of Shadecode Student.

## Vision
Every student interaction becomes an event that feeds Cortex.

Sources include:
- AI lessons
- Exam Hub
- Exam Simulation
- Tasks
- Timetable
- Analytics
- Community uploads
- XP and achievements

## Goals
- Personalized study recommendations
- Weak-topic detection
- Predictive exam readiness
- Continuous learning memory
- Event-driven architecture

## Principle
Features do not operate independently. They publish events to Cortex, which maintains a persistent academic profile and determines the next best learning action for every student.
