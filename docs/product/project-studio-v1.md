# Project Studio v1

Project Studio helps learners plan, conduct, document and present school projects from primary through secondary level. It is a learning/workflow tool, not a project-answer generator.

## Core flow

1. Create project: title, subject, level, board and brief.
2. Define research question.
3. Build methodology.
4. Capture evidence: notes, photos, documents, measurements, observations and sources.
5. Analyze evidence.
6. Draft report sections.
7. Prepare presentation/viva.
8. Review integrity warnings before submission.

## Offline requirements

Every step must work without network access. Project state and evidence metadata are persisted locally. AI is optional and must never be required to create, edit, save or advance a project.

## AI behavior

When a compatible local model exists, Project Coach may help brainstorm questions, explain methodology choices, suggest next steps, identify gaps and rehearse presentation questions. It must not fabricate respondents, measurements, observations, findings, sources or citations.

## Submission assistance

The product may provide structure, checklists, formatting guidance and learner-authored drafting assistance. It should preserve the learner's authorship and show where evidence is missing rather than silently filling gaps with invented content.

## Future expansion

Board-specific templates, primary-school project modes, multilingual support, teacher review, rubric mapping and project export formats can be layered on the same domain model.
