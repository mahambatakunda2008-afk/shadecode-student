# Shadecode Knowledge Changelog

This records changes to the project's strategic and operational knowledge system, not ordinary application commits.

## Entry format

- **Date:** YYYY-MM-DD
- **Change:** what changed
- **Reason:** why it changed
- **Artifacts:** affected blueprints/docs/prompts/labs/tasks
- **Decision:** related ADR, if any
- **Verification:** how the change was checked

## 2026-08-08

- Added the multi-agent coordination layer: protocol, handoff template, live handoff, knowledge map, and agent startup prompt.
- Added knowledge governance rules defining authority, artifact classes, blueprint governance, decision records, prompt governance, lab governance, audit freshness, and merge expectations.
- Added a decision-record template.
- Added a blueprint registry so historical blueprint work can be located before any missing material is reconstructed.
