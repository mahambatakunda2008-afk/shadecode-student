# Comp Lab Algorithm Assessment

Comp Lab now treats algorithms as assessable learning artifacts rather than terminal-only code.

## Model

`exercise -> objective -> test cases -> runtime evidence -> learning evidence`

The runtime executes the learner's pseudocode. The assessment layer can additionally compare normalized actual output against expected output for exercise-owned test cases.

## Curriculum alignment

The built-in objectives are intentionally board-neutral computing competencies. They are not presented as official Cambridge, ZIMSEC, university or polytechnic syllabus wording. Official syllabus references can be attached to an exercise/objective without changing the runtime.

## Evidence

Assessment evidence records the exercise ID, objective ID, pass state, number of tests and execution duration. This shape is suitable for later connection to the learning graph and mastery model.

## Current exercise modes

- Write an algorithm
- Trace / dry-run
- Flowchart structure
- Test cases
- Complexity reasoning

The next curriculum layer can attach verified board + syllabus + objective IDs and official assessment criteria to the same exercise model.
