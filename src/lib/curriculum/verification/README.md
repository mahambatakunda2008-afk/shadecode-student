# Production curriculum verification

A curriculum version is production-ready only when its authoritative document, whole-syllabus knowledge, assessment layers, provenance, and all completeness dimensions have been reconciled.

The verification manifests in this directory are deterministic assertions for known authoritative syllabus versions. They do not replace evidence from the official source document.

## Cambridge IGCSE Computer Science 0478, 2026-2028

Official document: https://www.cambridgeinternational.org/Images/697167-2026-2028-syllabus.pdf

Expected document: version 5, 56 pages.

Expected teaching structure: 10 topics covering data representation, data transmission, hardware, software, internet and its uses, automated/emerging technologies, algorithm design/problem solving, programming, databases, and Boolean logic.

Assessment: two externally assessed 75-mark papers, each 1 hour 45 minutes, each worth 50%, with no calculator use. Assessment objectives are AO1 40%, AO2 40%, AO3 20%.

Practical expectations are part of the teaching requirements. Verification must also reconcile syllabus guidance, command words, pseudocode/flowchart conventions, mathematical requirements, changes to the syllabus, and official support-resource provenance where applicable.
