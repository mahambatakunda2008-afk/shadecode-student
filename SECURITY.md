# Security Policy

Shadecode Student handles real student data (accounts, exam results, study
activity). If you find a security issue, please report it privately rather
than opening a public issue.

## Reporting

Contact: shadecodetech@gmail.com

Please include:
- A description of the issue and its potential impact
- Steps to reproduce
- Any relevant URLs, endpoints, or affected tables

## Scope

This covers the Next.js application, its API routes, and the Supabase
database schema/RLS policies in `supabase/migrations/`.

## Known accepted risks

See `docs/AUDIT_2026-08.md` for a record of past findings and how they were
resolved, and `CHANGELOG.md`'s "Known issues" section for currently open
items.
