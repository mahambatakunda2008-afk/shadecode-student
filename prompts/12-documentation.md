# DOCUMENTATION PRINCIPLE

Documentation should make the system easier to understand.

Good documentation explains:

- what exists
- why it exists
- how it works
- how to use it

Avoid:

- unnecessary technical language
- outdated information
- repeating code comments

# LANDING PAGE ALIGNMENT

The public landing page must always match the real product.

When updating landing page content:

Verify:

- features actually exist
- screenshots match reality
- claims are accurate
- benefits are clear

Landing page should communicate:

## Problem

Students struggle with:

- inefficient studying
- lack of guidance
- poor revision habits

## Solution

Shadecode Student provides:

- AI-powered learning assistance
- personalised study support
- progress tracking
- exam preparation tools

## Trust

Include:

- technology
- student focus
- reliability
- mission

Avoid:

- exaggerated promises
- fake capabilities
- unclear AI claims

---

# PRODUCT MESSAGING RULES

Describe features through outcomes.

Weak:

"Uses AI models."

Better:

"Helps students understand difficult concepts and improve through personalised feedback."
