# LANDING PAGE PRINCIPLE

The landing page has one mission:

Turn curiosity into action.

A visitor should quickly understand:

1. What is Shadecode Student?
2. Who is it for?
3. Why is it useful?
4. What should they do next?

# MESSAGE FRAMEWORK

The landing page should communicate:

## Problem

Students often struggle with:

- knowing what to study
- staying consistent
- understanding difficult topics
- preparing effectively for exams
- getting personalised support

## Solution

Shadecode Student helps students:

- learn smarter
- practise better
- understand mistakes
- track progress
- prepare for exams

## Differentiation

Highlight:

- AI-powered learning
- adaptive assistance
- student progress intelligence
- offline-friendly design
- built for real student needs

---

# HERO SECTION RULES

The hero must answer immediately:

What is this?

Why should I care?

What do I do next?

Include:

- clear headline
- supporting explanation
- primary action
- secondary action if needed

Avoid:

- vague AI buzzwords
- complicated explanations
- huge paragraphs

---

# FEATURE PRESENTATION RULES

Features should be shown as benefits.

Do not say:

"AI lesson generation system"

Say:

"Get personalised explanations and learning support when you need it."

Every feature section should explain:

Problem:

Solution:

Student benefit:

---

# TRUST RULES

The page should build confidence through:

- clear explanations
- real screenshots
- honest capabilities
- product examples
- student-focused messaging

Avoid:

- fake statistics
- exaggerated claims
- pretending unfinished features exist

---

# VISUAL RULES

The design should feel:

- modern
- intelligent
- educational
- trustworthy

Use:

- strong hierarchy
- clean spacing
- readable typography
- meaningful visuals

Avoid:

- clutter
- excessive animations
- generic AI imagery

---

# MOBILE RULES

Most students will discover products on phones.

Check:

- mobile layout
- button sizes
- loading speed
- image optimisation
- readability

---

# SEO RULES

Consider:

- page title
- metadata
- keywords
- structured content
- search intent

Target concepts:

- AI study assistant
- exam preparation
- student productivity
- personalised learning
- Cambridge learning support

Do not use misleading keywords.

---

# PERFORMANCE RULES

Landing page should load quickly.

Optimize:

- images
- fonts
- scripts
- animations

Avoid unnecessary libraries.

---

# CONVERSION FLOW

A visitor should move through:

Discover

↓

Understand

↓

Trust

↓

Try

Primary actions should be clear.

Examples:

- Start studying
- Create account
- Explore features

---

# IMPLEMENTATION RULES

When changing landing page:

- preserve existing app functionality
- reuse components where possible
- keep code clean
- do not create duplicate design systems

If major redesign is needed:

Explain first.
